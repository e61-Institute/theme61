# Set option to also open graphs in the browser

Previous versions of theme61 opened graphs in the browser instead of the
Viewer pane. You can bring back this functionality by running this
function, which sets a session-wide option. Graphs will still appear in
the Viewer pane as normal.

## Usage

``` r
set_open_graph_browser()

unset_open_graph_browser()
```

## Value

This function is used for its side effects.
